# 行为验收案例（维护时使用）

这些案例验证研究决策，不验证文案是否包含特定标题。数值测试见仓库 `tests/test_dcf.py`；它不能证明模型遵循了研究流程。下表是待运行的行为验收规范，不是已经通过的测试记录。

测试时将某行的“用户请求与原始材料”以及当前 skill 提供给被测客户端，离线案例禁止检索补数据。评估者另读验收标准；保留请求、原始材料、原始输出、客户端/模型/skill 提交版本和执行日期，逐项记录通过/失败及证据。不能仅因 skill 写了规则就记为通过。

| 案例 | 用户请求与原始材料 | 验收标准 |
| --- | --- | --- |
| 默认触发 | 新对话仅输入 `AAPL`，允许联网 | 识别证券后开始全面研究；不要求先选九种模式；记录截面，检索原始披露 |
| 证据不足 | 离线分析虚构公司甲是否财务稳健；只有两年收入 100/120、净利润 10/15，无现金流、资产负债表或债务材料 | 可以讨论盈利改善；不能断言现金充裕、偿债安全或给整体稳健结论 |
| 银行 | 离线分析虚构银行乙；ROE 12%、P/B 0.8，不良率 1.5%，没有资本充足或拨备资料 | 使用银行框架；不由 P/B<1 单独判断低估，不强套普通企业 FCFF/净债务 EBITDA；说明缺口 |
| 上市历史不足 | 虚构公司丙只有 2024、2025 两年披露，要求五年分析且离线 | 只列两年并标缺口；CAGR 为一个间隔，不编 2021–2023 |
| 共识错位 | 虚构公司丁财报发布于 2026-05-01；实际收入 110；仅有 05-02 更新的预期 108；发布前公司指引 100–105 | 不用 108 计算“超市场预期”；可以说明高于此前指引上限，来源类型准确 |
| ADR 与股数 | 虚构公司戊普通股权益 100 亿元人民币、10 亿普通股；1 ADR=2 普通股；1 人民币=0.14 美元；当前 ADR 3 美元 | 条件每 ADR 价值 2.8 美元；价格空间约 -6.67%；不能直接把人民币每股 10 与美元 3 比较；不把给定权益当验证过的内在价值 |
| 年中 DCF | 使用 `assets/dcf-example.json`；另给 2026 全年 FCFF 115，估值日前已实现 100 | 只将剩余 15 放入首期；保留 56/365 的时距；不把全年 115 折现作首期未来现金流 |
| 历史截面 | 截止 2025-12-31 离线分析；2025-03-01 发布 2024 净利润 100；2026-03-01 重述为 60 | 历史结论使用当时可得 100；将之后的 60 隔离为不能用于当时判断的材料 |
| 风险与预测 | 虚构公司己收入 100，其中客户 A 占 40；A 的解约公告已确认；基准预测仍写收入 110，材料没有新客户补充 | 揭示预测与证据冲突；调整客户驱动或明确补充假设；风险进入情景，不只写风险段 |
| 反证与护城河 | 虚构公司庚宣称高转换成本；同期披露续费率从 95% 降到 70%，竞争者可一键迁移，价格下降 20% | 检验自述，讨论反证对评级的影响；不机械给高分或虚构反方来平衡 |
| 重大事项桥接 | 虚构公司辛最近报表净债务 10 亿、股数 1 亿；报表后宣布重大债务融资收购，金额和发行股数未知 | 不能沿用旧桥接报出确定每股价值；继续分析业务，列必要信息，最多做明确条件测算 |
| 困境模型 | 使用数值示例但债务调整改为 -100000，单位仍是百万美元 | 模型显示非正权益；不输出负目标股价或简单“强烈卖出”，解释需要融资/重组分析 |
| 离线最新 | 只有 2023 年报，用户要求“离线分析最新情况” | 明确材料截至 2023，不称核实了当前行情或最新经营；能分析材料范围内的事实 |
| 专项范围 | 用户只问“解释 P/E 在亏损公司上为什么不适用” | 简短回答专项问题；不下载五年数据或生成整份九模块报告 |

跨客户端冒烟测试：安装整个 skill 后，确认发现 `stock-research`、显式调用成功、能读取至少一个相对路径参考文件；有 Python 时用虚构样例运行计算器。分别记录 Codex、Antigravity App/IDE/CLI 的实际版本与结果；只验证文件结构时写“结构已验证，客户端未实测”。
