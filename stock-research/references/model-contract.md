# DCF 计算工具与输入约定

## 支持范围

`scripts/dcf.py` 使用 Python 3.9+ 标准库，无网络和第三方依赖，输出普通 JSON。它计算给定现金流的现值，不生成财务预测、验证来源真实性或判断股票值得买入。首次使用先运行 `python3 <skill目录>/scripts/dcf.py --help`。

支持固定折现率、期末折现、ACT/365 时距、永续增长终值、FCFF 权益桥接、FCFE 直接权益估值、相同经济权利普通股的股数与 ADR/币种换算。包含负的显式预测现金流，但永续现金流必须为正。

不覆盖变动折现率、期中现金流、有限资产寿命、银行资本模型、优先级重组、复杂期权/可转债、不同经济权利股类和项目成功概率。需要这些能力时用适当模型，保留相同的证据和复算要求；不要为了使用工具扭曲业务假设。

## 使用

以下命令在仓库根目录运行；安装后将 `stock-research/` 换为实际 skill 路径：

```bash
python3 stock-research/scripts/dcf.py stock-research/assets/dcf-example.json
python3 stock-research/scripts/dcf.py model.json --output result.json --target-price 25
```

`--output` 仅创建新文件，避免覆盖已有报告；不提供时输出到终端。输入错误返回非零状态。示例数据全部虚构，只用于理解格式，不能用于真实股票建议。

## 输入字段（schema_version = 1）

每个对象只接受下表定义的字段，防止拼错字段被静默忽略。模型所有金额（现金流、桥接）使用同一 `currency` 和 `amount_scale`；股数始终用实际股数，每股报价始终用报价币种的基本单位。

| 字段 | 约定 |
| --- | --- |
| `as_of` | 估值日 YYYY-MM-DD；模型不支持日内现金流切分 |
| `currency` / `amount_scale` | 财务币种及量级；1、1000、10000、1000000、100000000、1000000000 之一 |
| `cash_flow_type` | FCFF 或 FCFE；预测计算与税/融资口径在底稿说明 |
| `discount_rate` / `terminal_growth` | 年化小数；r > 0，-1 < g < r；通过范围检查不代表经济合理 |
| `discount_rate_basis` / `terminal_growth_basis` | 折现率和长期增长的依据及假设/证据 ID；说明币种、名义/实际口径和风险假设 |
| `terminal_cash_flow` / `terminal_basis` | 最后显式期间之后一整年的正常化现金流（已含该年的增长/再投资），正值；依据及假设 ID。脚本不会再次乘 1+g |
| `periods` | 非空数组，每项含 `start`、`end`、`cash_flow`、`basis`；区间 `(start, end]`，首期从 as_of 开始，连续且有序，现金流在期末发生 |
| `bridge` | FCFF 下以估值日现值计的调整数组：`label`、带正负号的 `value`、`basis`；现金/非经营资产为正，债务/其他请求权为负，不能再折现或重复扣减 |
| `shares` | `count` 为实际普通股等价股数（不是“百万股”数字），`basis` 说明估值股数日期及稀释处理 |
| `quote` | `currency`；`fx_per_model_currency` 表示 1 单位财务币种对应多少报价币种；`ordinary_shares_per_quote_unit` 表示每份报价证券代表几股普通股；`basis` 记录汇率/ADR 来源与时点 |
| `sensitivity` | 非空 `discount_rates` 和 `terminal_growth_rates` 数组；建议各选至少三点，包含基准参数 |

现金流数据先在底稿从经营驱动推导：FCFF 可由 EBIT 税后利润、折旧、资本开支、营运资本变化计算；FCFE 还涉及利息、借款和还款。每期 `basis` 指向底稿计算/假设 ID。程序只能检查已填字段，无法识别把“全年现金流”错误标成“剩余期现金流”的语义错误，人工检查仍需完成。

FCFE 模式的 `bridge` 必须是空数组，避免重复减债。若 FCFE 估值需要另加未包含的非经营资产或涉及特殊请求权，使用有清晰桥接的专门模型，不向该简化接口塞入净债务。

普通股股数与财务金额量级互相独立。每份报价证券价值 = 权益金额 × amount_scale ÷ 实际普通股股数 × 汇率 × 每份证券对应普通股数。同币种汇率必须为 1。稀释股数的选取应与股权激励成本处理一致，计算器不替研究员决定。

## 输出与解释

结果包含输入快照、逐期时距/现值、终值及现值、权益桥接、每份证券价值、终值占比和敏感性矩阵。FCFE 的 `enterprise_value` 为 null；非正模型权益不会输出负股价，转为需要困境/重组分析的提示。

终值占 DCF 价值超过 80% 时给提示；这只是本工具的启发式关注点，不是行业标准或估值有效性的判定线。负的早期现金流可导致终值占比超过 100%，应解释来源。

敏感性矩阵固定下一年终值现金流，仅改变 r/g；不会联动修改再投资。它是参数敏感性，不是经济自洽的完整情景。r ≤ g 的单元标记无效而不生成数字。

`--target-price` 固定其余输入，反解当前价格需要的下一整年终值现金流。非正解标记模型不适用。反解不是收入增长率、市场共识或自动买卖信号；经营解释见[估值与情景](valuation-and-scenarios.md)。

实际交付至少包括：证据/假设底稿、模型输入、计算结果及简洁解释。脚本结果是估值日条件现值，不能直接充当未来 12–24 个月目标价。
