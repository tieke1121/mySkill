# 证据门槛与底稿

## 结论的最低证据

下表是结论准入条件，不是要求每次下载相同数量的报告。数据足够才形成相应结论；不足时说明缺口并继续其他分析。不要把“取不到数据”当成经营恶化的证据。

| 结论 | 最低证据 | 未满足时的输出 |
| --- | --- | --- |
| 标的身份与价格比较 | 公司、上市地、股份权利/类别、报价币种、价格时点可识别 | 标的不唯一时先澄清；没有可核实价格时不判断当前价格贵贱 |
| 五年财务趋势 | 实际可得期间的可比报表；增长和利润有口径调节 | 缩短至可验证期间，不补历史；只谈有证据的指标 |
| 财务健康/偿债能力 | 最新适用的利润表、现金流量表、资产负债表及重大债务/流动性附注 | 只有利润表时只能评盈利；偿债数据不足则暂缓“财务稳健”判断 |
| 护城河评级 | 有跨期经营结果支持的优势机制、可比竞争证据及反证检查 | 给定性假说，缺失维度不评分；不能用管理层自述给高分 |
| 内在价值/每股价值 | 可解释预测、再投资与融资假设、折现依据、相容股数及权益桥接 | 仅给明确标记的条件测算或不估值；桥接未解决不报每股合理价值 |
| 相对低估 | 同期价格、同口径财务指标及合理同行选择 | 仅列不可比项和缺口，不将样本倍数直接解释为低估 |
| 财报超/低于预期 | 发布前具名共识、与实际相同期间及会计口径 | 共识缺失不判断超预期；可与此前公司指引比较 |
| 市场低估某因素 | 当前价格隐含条件或可核实的市场预期，并有不同判断的证据 | 改为“本模型假设与价格的关系”，不声称掌握市场共识 |

## 新鲜度与冲突

- 分开记录报告期末、发布日期、数据取得日和报价时间。“最新报告”以已发布文件核实，不凭搜索排序判断。
- 从最新报表截止日至研究截止日查重大收购、融资、回购、拆股、分红、资产处置与业绩预警。若重大事项影响债务、股数或经营范围，做桥接；无法桥接时相应估值暂缓，不设虚假的统一“过期天数”。
- 历史时点分析的材料发布日期必须不晚于截止日；当时未知的重述、预测修订和实际结果不能回填。
- 冲突先核对原文、单位、期间、合并范围、会计口径和重述。保留冲突值及采用理由；影响关键论点且未解决的冲突必须进入摘要。
- 可靠二手资料可补足行情/共识/行业信息，注明提供者和取样时点。遇到访问失败，尝试其他合法来源；仍不可得就收窄结论，不绕过权限、不把搜索摘要当原文。

## 证据表与计算链

关键事实使用唯一证据 ID，字段可按报告形式实现为表格或 CSV/JSON：

| 字段 | 内容 |
| --- | --- |
| evidence_id / kind | ID；已披露事实、管理层指引、市场共识、分析假设之一 |
| metric / entity / scope | 指标、主体、合并/分部及股东归属范围 |
| period / published_at / retrieved_at | 覆盖期间或时点、发布/取得时间 |
| raw_value / unit / currency | 原文值、单位、币种；缺失为 null 而非 0 |
| basis / source / locator | 会计口径、直接链接或用户材料名、PDF 页码/表名/段落 |
| adjustments / used_value | 调整公式、原因、依赖证据 ID 和使用值 |

预测用假设 ID 连接经营驱动、来源和理由；计算结果用输入 ID 与公式连接，不将模型计算值标为披露事实。报价币种、金额量级、股份单位显式记录。公开底稿不包含凭据或账户隐私。

数值估值默认交付可复算的输入和结果：有文件工具时保存至当前任务可写目录并给链接；没有文件工具或用户只要文本时，在正文/附录提供紧凑表格或 JSON。不把报告写入 skill 安装目录或个人记忆库。专项定性问答只需引用与必要假设，不强制落盘。

## 三种置信判断

分别用高/中/低加一句原因，不取平均、不伪造概率：

- **数据可靠性**：关键事实是否有原始披露、期间是否匹配、冲突是否解决。
- **经营预测把握**：历史稳定性、可见订单/留存、行业周期、关键假设的证据强弱。
- **估值稳定性**：参数敏感性、终值依赖、方法差异与融资不确定性。

摘要中的结论遵守相应证据门槛；数据可靠并不意味着预测可靠。定稿时抽查核心判断能否沿“结论 → 计算/假设 → 原文”追溯。

结构化数据也需要上述核验：[SEC XBRL API](https://www.sec.gov/search-filings/edgar-application-programming-interfaces)按单位和期间提供数据，不能仅按标签名称拼接历史序列。
